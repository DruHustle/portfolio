# Professional Portfolio - Andrew Gotora

A responsive portfolio for Andrew Gotora, Senior Industrial Software & Digitalization Engineer and Co-Founder of Onesa UG. It showcases Industrial IoT and automation, AI platforms, cloud-native systems, and enterprise integration.

Onesa AI is a modular, self-hosted platform in development, built on open-weight foundation models. Its proposed model and application profiles are future plans.

## 🚀 Project Structure

```text
portfolio/
├── client/                 # Frontend React application (Vite + TS + Tailwind)
│   ├── public/             # Static assets (images, resume)
│   └── src/                # Application source code
│       ├── data/           # Project and skill data definitions
│       ├── pages/          # Main pages and project detail views
│       └── components/     # Reusable UI components
├── server/                 # Optional backend for advanced features
└── .github/workflows/      # CI/CD for GitHub Pages deployment
```

## 🛠️ Getting Started

### Prerequisites
- Node.js (v22+)
- PNPM (v9+)

### Installation
```bash
pnpm install
pnpm dev
```

## 🌐 Deployment
The portfolio is optimized for **GitHub Pages** using hash-based routing. Any push to the `main` branch will trigger an automated deployment via GitHub Actions.

## ✨ Key Features
- **Dynamic Project Details**: Deep-dive views for major projects like IMSOP and SAP BTP AI Hub.
- **Responsive Design**: Optimized for all devices with a focus on high-efficiency layouts.
- **Documentation Hub**: Integrated viewing and downloading of project documentation.
- **Analytics Dashboard**: Track portfolio visits and resume downloads at [Analytics Page](https://druhustle.github.io/portfolio/#/analytics).
- **Modern Tech Stack**: Built with React, TypeScript, Tailwind CSS, and Wouter.

## 🛠️ Technology Stack
- **Frontend Framework**: React 19
- **Styling**: Tailwind CSS 4 & shadcn/ui
- **Animations**: Framer Motion
- **Routing**: Wouter
- **Build Tool**: Vite
- **Package Manager**: pnpm
- **Language**: TypeScript
